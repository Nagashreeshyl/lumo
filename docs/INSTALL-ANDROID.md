# Install Lumo on Android

Lumo for Android is a regular APK. It isn't on the Play Store (YouTube's rules don't allow apps like this there), so you install it yourself. It takes a minute and never expires.

Requires Android 10 or newer.

## Install

1. On your phone, open the [latest release](https://github.com/Nagashreeshyl/lumo/releases/latest) and download **`Lumo-<version>.apk`**.
2. Open the downloaded file. Android asks to allow installs from your browser (or Files app): tap **Settings**, turn on **Allow from this source**, then go back.
3. Tap **Install**.
4. If **Play Protect** warns that it doesn't recognise the app, tap **More details → Install anyway**. It warns about every app that isn't from the Play Store.

Open Lumo and allow notifications, so the player controls show on the lock screen and in the notification shade.

## Update

When a new version is out, Lumo shows **"Lumo x.y is available"** as it opens. Tap **Update**, then **Install** (the first time, Android asks you to allow installs from Lumo). Your library stays.

You can also download the newer APK from the releases page and install it over the old one.

To get updates automatically, install [Obtainium](https://github.com/ImranR98/Obtainium), tap **Add App** and paste `https://github.com/Nagashreeshyl/lumo`. It checks the releases page and offers each new version.

## Moving your library

Your likes, playlists, stats and hidden songs can move between phones, including from an iPhone or Mac running Lumo:

1. On the old device: **Settings → Export Library**, and save the file somewhere you can reach from the new phone (Google Drive, email, etc.).
2. On the Android phone: **Settings → Import Library** and pick the file. Downloaded songs are downloaded again.

## Shortcuts

Long-press the Lumo icon for **Shuffle Liked Songs**, **Search** and your latest playlists.
